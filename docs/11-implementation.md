# 구현 상태 — 프리시즌 첫 버전

## 확정한 게임 경험

경쟁과 탐험을 같은 비중으로 구성했습니다. 첫 전국 지도는 입체 측면 없이 평평한 경계로 표시합니다. 도를 롤오버하면 해당 도만 34px 올라오며 전국 지도에 머뭅니다. 클릭해야 시·군·구 지형이 0.85초 동안 펼쳐지고, 마우스가 떠나면 도는 다시 평평해집니다. 세종시 같은 작은 지역도 고정된 원래 경계에서 선택할 수 있습니다. 시·군·구는 실제 경계 폴리곤으로 구성하며 롤오버하면 해당 땅이 22px 솟아오르고 원정 상태를 보여줍니다. 투명한 고정 히트 영역을 사용해 부상 애니메이션 중에도 클릭이 안정적으로 유지됩니다.

시·군·구 클릭은 지역별 문제 선택 화면으로 연결됩니다. 문항이 있는 3개 지역에는 16칸 선택, 없는 지역에도 같은 16칸 화면을 제공하며 문항 준비 중인 칸을 비활성화하고 탐험 기록을 남깁니다. 모바일에서는 도 탭 → 시·군·구 탭으로 진행합니다. 목록 검색과 키보드 접근도 제공합니다.

확정 규칙: 16칸 중 서로 다른 4칸 자유 선택, 단계 중복 허용, 문제당 30초, 기본 점수 100/150/200/300, 처음 3초 최대 1.2배 후 선형 감소. 콤보는 점수에 별도 가산하지 않고 연출과 배지에 적용합니다.

## 실제 코드 구조

- app/: Next.js App Router, 루트 첫 화면과 로컬 시연 API.
- components/: 입체 지도, 대시보드, 문제 선택·풀이·결과.
- lib/: 한글 지역 데이터, 문항, 탐험 기록, Firebase 연결 계층.
- packages/shared/game.ts: 점수·선택 검증·함수 계약.
- functions/: Firebase callable 함수. 원본 공통 로직과 문항은 빌드 때 동기화합니다.
- public/geo/: 시·도 및 시·군·구 실제 경계.
- public/art/: 직접 생성한 3종 일러스트 원본과 웹용 최적화 파일.
- tests/: 점수, 문항, 지도, 기록 및 실제 브라우저 동작 테스트.

## Firebase 연결

프로젝트 test-e27db, Firestore 및 Functions 리전 asia-northeast3. Google 로그인과 익명 게스트 로그인을 사용합니다. 새 Google 계정으로 전환할 때 익명 계정을 연결해 UID와 원정 기록을 유지합니다. 이미 존재하는 Google 계정이면 그 계정의 기존 기록으로 전환합니다.

함수는 localwarStartSession, localwarBeginQuestion, localwarSubmitAnswer, localwarFinishSession, localwarDiscoverRegion, localwarGetProgress입니다. 정답과 해설은 답 제출 전에는 전송하지 않습니다. 시작과 채점은 서버 시각을 사용합니다. 제출·완료를 반복해도 같은 결과를 반환하고 XP가 중복 적용되지 않습니다.

localwarSessions는 클라이언트 읽기·쓰기를 모두 차단하고, localwarProfiles는 본인 읽기만 허용합니다. 기존 프로젝트의 users 규칙은 보존했습니다. 서버 기록과 현재 개인 점령 게이지를 Firestore에 저장하며 프로필 변경을 구독합니다.

비공개 서비스 계정 키를 소스·Git·Vercel에 저장하지 않았습니다. 배포는 이미 인증된 jejuailabs CLI 계정, 함수 실행은 Google 관리 서비스 계정을 사용합니다.

## 배포

GitHub: jejuailabs/localwar, main.
Vercel: jejuai 팀의 기존 localwar 프로젝트. 공개 Firebase 웹 설정과 firebase 모드를 production/preview 환경에 설정했습니다.
Firebase: localwar 코드베이스에만 함수를 배포했습니다. 최대 인스턴스는 함수별 3, 최소 0이며 컨테이너 빌드 이미지는 7일 정리 정책을 사용합니다.

## 검증과 현재 범위

로컬 점수·문항·지도·중복 기록 검증, Firebase 서버 엔진 검증, PC·모바일 지도 선택과 완전한 원정, 실제 터치, 30초 자동 종료를 검사합니다. 실제 Firebase에서도 4문제 모두 정답, 480점·4콤보 저장, 중복 완료 방지, 다른 사용자 세션 접근 거부, 세션 직접 읽기 거부를 확인했고 테스트 데이터는 정리했습니다.

현재 3개 지역의 144개 체험 문항과 별도 데일리 30문항 모드가 있습니다. 로그인 계정의 하루 지역 공격 3회와 데일리 지원 1회, 90/10 일일 지역 집계를 연결했습니다. 높은 단계의 문항 풀 확대와 난이도 검수, 최신 행정 경계 교체, 팀 대항 점령 집계·시즌·관리자·다국어·App Check·부하 검증은 전국 출시를 위한 후속 범위입니다. 현재 UI는 개인 프리시즌 진행도를 명시하며 가상의 실시간 상대나 접속 수를 표시하지 않습니다.

## 배포 완료 확인

https://localwar.vercel.app — jejuailabs의 jejuai/localwar 프로덕션 배포입니다. 배포된 브라우저에서도 게스트 인증, Cloud Functions 출제·채점, 4문제 모두 정답, 새로고침 후 기록 복원, 콘솔 오류 없음까지 확인했습니다. GitHub CI의 타입·빌드·단위·브라우저 검증도 통과했습니다.

데일리와 참여 편차 보정의 상세 구현은 [12-daily-conquest.md](12-daily-conquest.md), 신규 문항 검수는 [13-question-bank-sources.md](13-question-bank-sources.md)를 참고합니다.

## 첫 화면 지도와 공식 사진 배너 (2026-10-11)

전국 지도의 기본 투영 범위와 화면 높이를 늘렸습니다. 초기 지도는 평면이고, 시·도에 마우스를 올리면 그 지역만 솟아오르며 클릭해야 시·군·구 지도로 이동합니다. 확대·축소는 80~200%, 현재 배율 표시, 전체 보기 복귀와 확대 상태 드래그 이동을 지원합니다. 전국 및 시·군 지도에 같은 변환을 적용했고 CSS 이동 좌표에 px 단위를 명시해 브라우저가 변환을 무시하던 문제를 수정했습니다. 시·군 등장 애니메이션은 확대 변환과 별도 그룹으로 분리했습니다.

서귀포·충주·종로와 첫 원정 추천 배너는 공식 기관에서 공개한 공공누리 제1유형 실제 사진으로 교체하고 화면에 원출처 링크를 표시합니다. 아직 사진이 확보되지 않은 지역에는 다른 지역의 사진을 대신 쓰지 않습니다. 상세 출처는 14-official-photo-sources.md에 기록합니다.

## 퀴즈 진행 중 모바일 메뉴·로그인 수정 (2026-10-11)

퀴즈 진행 중 브랜드·메뉴·로그인 버튼을 일괄 비활성화하던 코드를 제거했습니다. 다른 메뉴 또는 로그인/로그아웃을 선택하면 전환 안내가 표시되며, 취소하면 기존 문제에 남습니다. 데일리 메뉴로 바로 나가면 로비에서 같은 세션을 이어할 수 있고 다른 메뉴에서 돌아오면 저장된 데일리를 자동으로 이어합니다. 이미 시작한 문제의 서버 제한 시간은 초기화되지 않습니다. 지역 원정은 나가기 전에 완료 보상과 시작 시 소비된 공격 횟수를 안내합니다.

전환 창이 열린 동안 숫자·Enter 퀴즈 단축키를 차단하고 Escape 취소 및 포커스 복귀를 지원합니다. 로그인 중에만 계정 버튼을 잠그며 로그인 취소·팝업 차단도 안내합니다. 모바일 상단 로그인 버튼과 닉네임이 여러 줄로 깨지지 않도록 간격과 표시를 조정했습니다. tests/navigation.spec.ts에서 4번째 데일리 문제의 메뉴 5개 전환·이어하기·시간 보존·취소·단축키·지역 원정 이동을 검증합니다. scripts/test-navigation-production.mjs는 실제 배포 주소에서 게스트 데일리 중 메뉴 전환과 Google 로그인 창 진입·취소 복구를 확인하고 자체 테스트 데이터를 정리합니다.
