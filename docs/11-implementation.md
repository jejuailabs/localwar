# 구현 상태 — 프리시즌 첫 버전

## 확정한 게임 경험

경쟁과 탐험을 같은 비중으로 구성했습니다. 전국 지도에서 도를 롤오버하면 해당 도가 34px 올라오고, 약 0.42초 후 시·군·구 지형이 0.85초 동안 펼쳐집니다. 시·군·구는 실제 경계 폴리곤으로 구성하며 롤오버하면 해당 땅이 22px 솟아오르고 원정 상태를 보여줍니다. 투명한 고정 히트 영역을 사용해 부상 애니메이션 중에도 클릭이 안정적으로 유지됩니다.

시·군·구 클릭은 지역별 문제 선택 화면으로 연결됩니다. 문항이 있는 3개 지역에는 16칸 선택, 없는 지역에는 문항 준비 안내와 탐험 기록을 제공합니다. 모바일에서는 도 탭 → 시·군·구 탭으로 진행합니다. 목록 검색과 키보드 접근도 제공합니다.

확정 규칙: 16칸 중 서로 다른 4칸 자유 선택, 단계 중복 허용, 문제당 30초, 기본 점수 100/150/200/300, 처음 3초 최대 1.2배 후 선형 감소. 콤보는 점수에 별도 가산하지 않고 연출과 배지에 적용합니다.

## 실제 코드 구조

- app/: Next.js App Router, 루트 첫 화면과 로컬 시연 API.
- components/: 입체 지도, 대시보드, 문제 선택·풀이·결과.
- lib/: 한글 지역 데이터, 문항, 탐험 기록, Firebase 연결 계층.
- packages/shared/game.ts: 점수·선택 검증·함수 계약.
- functions/: Firebase callable 함수. 원본 공통 로직과 문항은 빌드 때 동기화합니다.
- public/geo/: 시·도 및 시·군·구 실제 경계.
- public/art/: 직접 생성한 3종 일러스트 원본과 웹용 최적화 파일.
- tests/: 점수, 문항, 지도, 기록 및 실제 브라우저 동작 테스트.

## Firebase 연결

프로젝트 test-e27db, Firestore 및 Functions 리전 asia-northeast3. Google 로그인과 익명 게스트 로그인을 사용합니다. 새 Google 계정으로 전환할 때 익명 계정을 연결해 UID와 원정 기록을 유지합니다. 이미 존재하는 Google 계정이면 그 계정의 기존 기록으로 전환합니다.

함수는 localwarStartSession, localwarBeginQuestion, localwarSubmitAnswer, localwarFinishSession, localwarDiscoverRegion, localwarGetProgress입니다. 정답과 해설은 답 제출 전에는 전송하지 않습니다. 시작과 채점은 서버 시각을 사용합니다. 제출·완료를 반복해도 같은 결과를 반환하고 XP가 중복 적용되지 않습니다.

localwarSessions는 클라이언트 읽기·쓰기를 모두 차단하고, localwarProfiles는 본인 읽기만 허용합니다. 기존 프로젝트의 users 규칙은 보존했습니다. 서버 기록과 현재 개인 점령 게이지를 Firestore에 저장하며 프로필 변경을 구독합니다.

비공개 서비스 계정 키를 소스·Git·Vercel에 저장하지 않았습니다. 배포는 이미 인증된 jejuailabs CLI 계정, 함수 실행은 Google 관리 서비스 계정을 사용합니다.

## 배포

GitHub: jejuailabs/localwar, main.
Vercel: jejuai 팀의 기존 localwar 프로젝트. 공개 Firebase 웹 설정과 firebase 모드를 production/preview 환경에 설정했습니다.
Firebase: localwar 코드베이스에만 함수를 배포했습니다. 최대 인스턴스는 함수별 3, 최소 0이며 컨테이너 빌드 이미지는 7일 정리 정책을 사용합니다.

## 검증과 현재 범위

로컬 점수·문항·지도·중복 기록 검증, Firebase 서버 엔진 검증, PC·모바일 지도 선택과 완전한 원정, 실제 터치, 30초 자동 종료를 검사합니다. 실제 Firebase에서도 4문제 모두 정답, 480점·4콤보 저장, 중복 완료 방지, 다른 사용자 세션 접근 거부, 세션 직접 읽기 거부를 확인했고 테스트 데이터는 정리했습니다.

현재 3개 지역의 48개 체험 문항이 있습니다. 높은 단계의 문항 풀 확대와 난이도 검수, 최신 행정 경계 교체, 팀 대항 점령 집계·시즌·관리자·다국어·App Check·부하 검증은 전국 출시를 위한 후속 범위입니다. 현재 UI는 개인 프리시즌 진행도를 명시하며 가상의 실시간 상대나 접속 수를 표시하지 않습니다.
