# 01. 제품 개요 및 게임 규칙

## 1. 콘셉트

- **대한민국 전체가 하나의 게임판**: 지역 퀴즈 + 전략적 난이도 선택 + 실시간 지도 점령 + 지역 공동체 간 경쟁
- 장기 확장: 전국 지역 상식 데이터베이스, 지역 문화 콘텐츠, 지자체 참여형 홍보 채널

## 2. 타깃 사용자

| 구분 | 설명 |
|---|---|
| 핵심 | 지역 연고 의식이 있는 10~50대, 퀴즈·경쟁 콘텐츠 선호층 |
| 확장 | 가족 단위(초등 고학년 포함), 지역 축제 방문객, 지자체 홍보 대상 |

> 초등 3~4학년 수준 문제부터 시작하므로 **만 14세 미만 가입 가능성**이 있습니다. 처리 방안은 [04-auth-and-roles.md](04-auth-and-roles.md#6-미성년자-처리) 참고.

## 3. 게임 흐름

```
전국 지도 (점령 현황 · 경합 지역)
   └─ 시·도 선택 (예: 충청북도)
        └─ 시·군·구 선택 (예: 충주시)
             └─ 16칸(4분류×4단계) 중 4칸 선택
                  └─ 4문제 풀이 (문제당 제한시간)
                       └─ 서버 채점 → 개인 점수 → 지역 점령도 반영
```

### 행정구역 퀴즈 단위

| 지역 | 퀴즈 단위 |
|---|---|
| 서울특별시 | 자치구 |
| 광역시 | 구·군 |
| 일반 도 | 시·군 중심 (필요 시 구) |
| 제주특별자치도 | 읍·면·동 |

관리자가 지역별로 퀴즈 단위를 조정할 수 있어야 합니다 (`regions.quizUnit` 필드, [03](03-data-model.md) 참고).

## 4. 퀴즈 시스템 — 4×4 구조

| 분류 \ 단계 | 1단계 | 2단계 | 3단계 | 4단계 |
|---|---|---|---|---|
| 역사·문화 | 100 | 150 | 200 | 300 |
| 인물·대중문화 | 100 | 150 | 200 | 300 |
| 특산물·음식 | 100 | 150 | 200 | 300 |
| 관광·지역상식 | 100 | 150 | 200 | 300 |

- 16칸 중 **정확히 4칸 선택**, 칸마다 1문제 출제
- 선택 4칸 최대 기본점수: 300×4 = **1,200점** (같은 단계 중복 선택 허용 시). 기획서 예시의 "750점"은 특정 조합(예: 100+150+200+300) 기준으로 보이며, **분류·단계 중복 허용 여부는 확정 필요**합니다.
- 1단계는 초등 3~4학년 수준, 단계가 오를수록 이야기 이해·지역 지식 요구
- 사투리, 지역 축제, 연예인·스포츠인, 최근 지역 이슈는 4개 분류에 편입

## 5. 점수·점령 (요약)

상세 수식과 구현은 [05-game-logic.md](05-game-logic.md) 참고.

- 개인 총점 = Σ(기본점수 × 정답여부 × 시간계수), 시간계수 1.0~1.2 (서버 검증)
- 점령력 = 참여자 평균점수 × √유효참여자수 (초기 가설, 테스트로 보정)
- 장시간 반복 플레이만으로 점령되지 않도록 일일 반영 제한

## 6. 점령·방어·시즌

- 사용자는 **소속 지역**을 정하고 다른 지역에 원정(공격)하거나 자기 지역 퀴즈로 방어
- 지역 상태: `중립` / `점령(점령 지역 표시)` / `경합`
- 격전지 실시간 공개, 역전·점령 시 전국 지도 업데이트
- **주간 시즌제**: 매주 월요일 00:00(KST) 점령 전적 리셋, 개인 누적 기록·역대 업적은 보존

## 7. 미확정 규칙 및 확인 필요 사항

### 7.1 기획서상 미확정 (개발 전 확정 필수)

| # | 항목 | 제안 초안 (가설 — 테스트로 조정) |
|---|---|---|
| 1 | 지역 소속 기준 | 가입 시 "응원 지역" 1곳 선택(거주·출신 무관), **시즌당 1회 변경**, 변경 후 7일간 방어 점수만 반영 |
| 2 | 점령 판정 | 유효참여자 **최소 30명**, 점령력 점유율 **55% 이상**을 **6시간 연속** 유지 시 전환 |
| 3 | 반복 도전 | 지역당 **하루 3회**까지 점령 점수 반영, 같은 문항 재출제 간격 **14일** |
| 4 | 시즌 보상 | 점령 지역 소속원에게 시즌 배지, 개인 기여 상위 10%에게 칭호, 누적 업적에 기록 |

> 위 수치는 모두 **임의 초안**이며 근거 데이터가 없습니다. 베타 테스트 데이터로 결정해야 합니다.

### 7.2 시안(B안·D안)과 기획서 간 불일치

| 항목 | 기획서 | 시안 | 조치 |
|---|---|---|---|
| 시간 보너스 | 시간계수 최대 1.2배 (100점 → 최대 120점) | 기본 100 + 시간보너스 30 = 130점 (1.3배) | 둘 중 하나로 통일 필요 |
| 누적 점수 분모 | 4문제 최대 750점(예시) | "130 / 400점" | 분모 의미(1단계×4?) 확인 필요 |
| 단계 표시 | 분류×단계 자유 선택 | 탭이 "역사·문화 1단계 / 인물 2단계 / 특산물 3단계 / 관광 4단계"로 고정된 것처럼 보임 | 사용자가 선택한 4칸을 탭으로 표시하는 것인지 확인 필요 |
| 제주 퀴즈 단위 | 읍·면·동 | "제주도 방어전" (도 단위) | 방어전 단위(도 vs 읍면동) 결정 필요 |
