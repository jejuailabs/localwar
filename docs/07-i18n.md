# 07. 다국어 (i18n)

## 1. 지원 언어

| 로케일 | 단계 | 비고 |
|---|---|---|
| `ko` | MVP (기본·원문) | 모든 콘텐츠의 기준 언어 |
| `en` | MVP | 외국인 관광객·교포 |
| `ja` | 2차 | |
| `zh-CN` | 2차 | 필요 시 `zh-TW` 추가 |

> 언어 우선순위는 제안입니다. 실제 방문자 언어 통계를 보고 조정합니다.

## 2. 범위 구분

| 대상 | 방식 |
|---|---|
| UI 문자열 (버튼, 안내, 오류) | `messages/{locale}.json` — 코드와 함께 버전 관리 |
| 지역명 | `regions.names[locale]` — 공식 영문 표기 우선 (예: 국립국어원 로마자 표기, 지자체 공식 표기) |
| 퀴즈 문항·해설 | `questions.content[locale]` — 번역 후 **별도 검수 상태** |
| 날짜·숫자 | `Intl.DateTimeFormat` / `Intl.NumberFormat` (시즌 시간은 항상 KST 기준 표시 + 현지 시간 병기) |

## 3. 라우팅

- URL 접두사 방식: `/ko/map`, `/en/map` (SEO, 공유 링크 언어 고정)
- `middleware.ts`: 접두사 없는 요청 → ① 로그인 사용자의 `users.locale` 쿠키 ② `Accept-Language` ③ `ko` 순으로 리다이렉트
- `<html lang>`과 `hreflang` 대체 링크 출력
- 언어 전환 드롭다운: 헤더(테마 토글 옆), 현재 경로 유지한 채 로케일만 교체

```ts
// middleware.ts (next-intl 예시)
import createMiddleware from 'next-intl/middleware';
export default createMiddleware({
  locales: ['ko', 'en', 'ja', 'zh-CN'],
  defaultLocale: 'ko',
  localePrefix: 'always',
});
export const config = { matcher: ['/((?!api|_next|.*\\..*).*)'] };
```

## 4. 메시지 파일 규칙

```json
// messages/ko.json
{
  "nav": { "map": "전국 지도", "ranking": "랭킹", "missions": "미션", "me": "내 정보" },
  "quiz": {
    "progress": "{current} / {total}",
    "timeLeft": "남은 시간 {seconds}초",
    "pickCount": "{count}/4 선택",
    "start": "4문제 도전",
    "next": "다음 문제로"
  },
  "category": { "history": "역사·문화", "people": "인물·대중문화", "food": "특산물·음식", "tour": "관광·지역상식" },
  "level": "{n}단계",
  "theme": { "toggle": "다크 모드 전환", "system": "시스템", "light": "라이트", "dark": "다크" }
}
```

- 키는 영문 계층형, 문장 조립 금지 → ICU 플레이스홀더 사용
- 복수형·성별 표현은 ICU `plural`/`select` 사용 (영어 "1 point / 2 points")
- CI에서 **키 누락 검사**: `ko`에 있는 키가 다른 로케일에 없으면 경고(2차 언어) / 실패(MVP 언어)
- 문자열 길이: 영어·독일어류는 한국어보다 길어짐 → 버튼은 `min-width` + 말줄임 대신 줄바꿈 허용

## 5. 퀴즈 콘텐츠 번역 정책

지역 상식 퀴즈는 **번역 시 의미가 깨지는 문항**이 많습니다.

| 유형 | 정책 |
|---|---|
| 일반 사실 (역사, 특산물) | 번역 제공 |
| 사투리 의미, 언어유희, 한글 자모 관련 | `translatable: false` → 해당 언어에서 출제 제외 또는 "한국어 원문 + 설명" 형태 |
| 인물·대중문화 | 인명 표기 확인 (공식 영문명), 최신성 재검증 |

### 번역 워크플로

```
ko 승인 문항 → AI 번역 초안(en/ja/zh-CN) → 상태 translation_review
  → 해당 언어 검수자 승인 → content[locale] 공개
```

- 언어별로 승인 문항이 부족한 칸은 16칸 화면에서 비활성
- 랭킹·점령은 **언어 무관 공통 집계** (같은 지역·단계면 언어가 달라도 동일 점수). 단 번역 문항 정답률이 원문과 크게 다르면 검수 대상

## 6. 어드민 다국어

- 어드민 UI는 MVP에서 **ko만** 지원 (운영 인력 기준)
- 문항 편집기에 언어 탭 (ko | en | ja | zh-CN), 원문 대비 나란히 보기, 번역 상태 배지
