## 사실·보기 검토

모든 채택 URL은 본문을 열어 확인했다. 한국관광공사의 안반데기·정동진 안내는 본문에 강원도청 제공이라고 표기되어 있다. 고유명사·연도·수치는 공식 본문을 기준으로 대조했고 기사 문장을 복사하지 않고 문항·해설로 재서술했다. 각 셀 3개, 문항 ID 48개, factId 48개, 4지선다 중복 없음과 JSON 연결을 기계적으로 확인한다.

홍길동전의 저자 문제는 ‘강릉시 인물 안내에서’라는 출처 범위를 명시한다. 경포호 장자못은 전설의 기록 문헌만 묻고 실제 호수 형성 원인으로 취급하지 않는다. 장칼국수 기원 역시 ‘전해진다’는 성격을 유지한다. 경포대 ‘제일강산’ 현판 글씨처럼 공식 자료가 불확실하다고 밝힌 사실은 채택하지 않았다. 강릉시 허난설헌 페이지의 정유왜란 연도 오기는 사용하지 않았다. 운영시간·요금·축제 당해 일정·방문객 수처럼 변할 수 있는 정보도 문항에서 제외했다.

## HTTP 원문 재확인

통합 검수에서 웹 추출 누락이 의심된 두 사실은 2026-10-11에 HTTP GET 원문으로 다시 확인했다. 두 요청 모두 200 응답이고 최종 URL이 요청 URL과 동일하여 리다이렉트가 없었다.

- `gangwon-gangneung-food-4-bank-3`: 제례음식 원문의 `<p>`에 “소나무의 솔잎을 넣어 송엽두견주”가 있다.
- `gangwon-gangneung-travel-4-bank-2`: 경포호 여행기 원문의 `<p class="txt">`에 “농경지 29만m2를 매입하여”가 있다.
